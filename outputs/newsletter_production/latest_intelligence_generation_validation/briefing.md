## Founder Lessons

- Use the first LP meeting to learn fit before pitching.
- Build entry, exit, and executional discipline if you want to be a fund manager, not only a good investor.
- Keep your investing framework and inputs consistent so you can learn from one decision to the next.
- Talk to enough managers in an asset class before investing so you understand what quality looks like.
