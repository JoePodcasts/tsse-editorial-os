# Phase 2 · approved theme browser

Begin after a human signs off the catalogue, individual display excerpts and their relationships. Freeze a release containing approved theme IDs, review metadata and the precise source fingerprints reviewed. Validate all joins against the target deployed archive. Decide which of the nine labels and contextual examples survive review.

1. At build time, resolve the approved release against the catalogue and passage index. Emit a compact public card list and one detail payload per slug. Exclude review notes, private paths, candidates, rejected records and relationships to unpublished themes. A changed source invalidates the affected excerpt until reviewed. Keep the previous valid release available for rollback.
2. Extend the existing homepage with an “Explore by theme” section alongside search and episode browsing. Read names, descriptions and counts from the approved list. Use the existing typography, spacing and link styles. Give each card one descriptive link to `/themes/<stable-slug>`. Preserve slugs across display-name changes; retire or redirect a slug deliberately.
3. Add a direct-loadable theme detail route and host rewrite consistent with current episode navigation. Show the proposition, representative episodes, curated passages, qualifications, contrasts and approved related themes. Link titles to the existing episode route and quotations to the existing transcript reader with its passage parameter. Provide the original episode link. Label genuine start times and omit absent times. Handle stale references with an episode-level fallback and an editorial repair signal.
4. Use a single-column reading order on narrow screens and a responsive card grid when space permits. Keep excerpts selectable, headings hierarchical, links keyboard reachable, focus visible and status conveyed in text. Preserve browser back navigation and the user's prior search. A zero-theme release should leave archive browsing usable.
5. Test a clean approved release, an unapproved record, changed transcript, missing timestamp, unknown speaker, related unpublished theme, direct reload, browser back, keyboard-only navigation and a narrow viewport. Run existing archive, frontend and deployment suites before any separately authorized release.
